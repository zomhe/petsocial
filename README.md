# 犬友社区微信小程序

面向单个或少量城市社区养狗用户的微信小程序产品与研发基线。首期围绕“狗狗身份”建立晒宠、附近犬友、结构化遛狗邀约和单一合作宠物幼儿园服务闭环。

## 版本基线

- 文档版本：v0.1
- 当前阶段：需求基线，待业务确认
- 试点范围：单社区、邀请制、只服务养狗用户
- 北极星指标：每周完成至少一次有效社区互动的狗狗数量
- 明确不做：私信、群聊、实时位置共享、商城、直播、在线医疗、领养交易、婚配、保险、开放商户入驻、猫及异宠

## 阅读约定

- P0：试点上线与核心闭环不可缺少。
- P1：灰度阶段应补齐，允许受控人工兜底。
- P2：验证核心闭环后再评估。
- “公开”不等于所有登录用户可见；公开范围仍受社区、隐私开关、拉黑和治理状态约束。
- 所有时间存储为 UTC，展示时按运营城市时区转换。
